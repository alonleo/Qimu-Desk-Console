# 知识库分类与标签

工作台知识库页右上角的「管理分类和标签」允许管理员维护共享目录。普通成员仍可为自己有权编辑的文档选择分类、添加或移除标签。

- 新分类立即进入两端分类列表；新标签即使未关联文档也持久保存，计数为 0。
- 删除分类时，将对应文档移到「未分类」；默认分类不能删除或重命名。
- 删除标签时，精确移除所有文档中的同名标签，不影响相似名称，不删除文档。
- 删除前展示影响提示并要求确认；失败保留输入，刷新列表后恢复可重试状态。
- 管理共享目录前若有未保存文档，会先提示保留或放弃修改。

分类沿用共享 `categories` 表；标签目录使用新增的 `knowledge_tags` 表，原有 `docs.tags` 数据保持兼容。Java 启动时执行幂等增量建表，Desk 与 Console 读取同一数据库。目录增删由 Java 后端负责鉴权，Desk 代理保留登录检查和来源检查；分类删除和标签引用清理由事务保护。

上线顺序：备份数据库及应用，先部署 Java 后端并确认 `knowledge_tags` 已建立，再部署工作台。回滚应用无需删除新增表。

验证命令：

- Desk：`node scripts/qa-knowledge/core.cjs`、`node scripts/qa-knowledge/taxonomy-proxy.cjs`、`npm run build`。
- Java：`mvn test`；覆盖共享目录权限、无效输入、默认分类保护、空标签、精确移除和历史分类迁移。
